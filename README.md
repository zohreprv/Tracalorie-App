# 🍴 Tracalorie

> A mini calorie-tracking application for managing meals and workouts.

## 🌐 **[Live Demo](https://tracalorie-app-kohl.vercel.app/)**

## 📌 About

### Tracalorie was originally a project exercise from **Brad Traversy's JavaScript course**, which I rebuilt using **React and TypeScript** to practice modern React concepts.

---

## ✨ Features

- 🍽️ Add and delete meals with calorie information
- 🏋️ Add and manage workouts
- 🔍 Filter meals and workouts
- 🧮 Track total calories
- 💾 Persist data with Local Storage
- 📱 Responsive design

---

## 🛠️ Tech Stack

- ⚛️ React
- 📘 TypeScript
- 🎨 Bootstrap
- 🔄 Context API
- 💾 Local Storage
- ⚡ Vite

---

## 🚀 Getting Started

```bash
npm install
npm run dev
```
